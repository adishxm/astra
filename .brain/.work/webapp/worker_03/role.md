# Worker 03 — Risk, Context & Migration Decision Support

## Mission
Turn the completed MVP inventory into explainable, assumption-aware priorities and advisory migration actions.

## Phase-count policy
The number of phases is chosen from this workstream's deliverables and dependency gates, not copied from another worker. See `phase_index.md`; unlike the other roles, this role has its own number of MVP phases. The phase boundaries ensure all in-scope MVP outputs reach an integrated handoff.

## Boundaries and obligations
Planning only; no application source or runtime logic is created. Production phases begin only after the complete MVP planning gate. Preserve uncertainty, use agreed contracts, update traceability/shared logs, and submit a specific report and handoff for every phase. Future paths are references, not files created now.
